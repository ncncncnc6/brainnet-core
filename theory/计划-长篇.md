# 长效计划：brainnet-core 八阶段推进（plan/1.0.0）

> 目标（已激活）：按五条工作范式持续推进到每阶段判据通过。目标 id `goal-826b390d-4b29-4fd0-a44b-6eac460bc446`，上限 60 轮。
> 本文件是**唯一排期表**：每阶段有编号、判据、依赖、产出件；每轮开工先读它，做完**当场更新状态列**。

## 执行原则（五条范式，每轮自检）

1. 对账先行：先读本表 + `theory/audit/需求对账.md`，确认本轮做哪条、不重复已完成的。
2. 建模式化：能写方程就写方程（动力学/代数/概率），缺资料先查语料或检索，不编造。
3. 损失/代价：每条路标出**代价**与**卡住谁**；一条路走不通先怀疑模型不足，不加大扫描量。
4. 看图：每个阶段性结论必须出一张图并**真看**（`read_image`），图与数字不一致先查口径。
5. 模式识别：比较结构时判定**同调**（全局不变量，如 b₁）还是**同构**（局部型，如 motif）。

## 每阶段完成时的动作（固定流程）

1. 该阶段判据件 `exit=0`，且**负例必须失败**；
2. 出图并 `read_image` 看过；
3. 结论写进 `theory/audit/完整性核对.md`（或专题文档），标注四态；
4. 更新本表状态列；跑三道闸门（编译 / 30 件全量 / 探针）；
5. 若结论推翻了旧断言，旧断言标 **过期** 并在同句给出替代。
