# 理论节：距离律的泛函形式与求解（theory/1.0.0）

> 本节**独立成篇**，位于 `theory/`，不改动 `brainnet-core/` 下任何实现件。
> 求解件：[solve_functional.py](<solve_functional.py>)。文献原件在 `papers/`，清单见 `papers/MANIFEST.md`。

## 一、泛函的出处（逐字，可核对）

| 要素 | 原文（逐字） | 出处 |
| --- | --- | --- |
| 泛函的**形式** | 「The balance in the model is modulated by a balancing factor ( b f ). If b f is zero, dendritic trees minimize the cable only, and if b f is one, equal weight is given to minimizing conduction delays and total dendritic length.」 | PMC11790248（eLife 2025，树突生长） |
| 泛函的**两侧**与实测效率 | 轴突乔木在**材料**与**传导延迟**之间权衡；最小长度图用 Euclidean Steiner minimal tree 度量；报告 spiny 细胞效率 `ε_spiny = 0.86 ± 0.04` | PMC2837396（PLoS Comput Biol 2010） |
| 指数衰减的**形式** | `ℙ(J_ij = 1) = exp(−λ_decay · d_ij)`；λ 的 MLE 验证真值 1.2–3.2 mm⁻¹（R=0.93），插图另有 1 / 2 / 10 mm⁻¹ | PMC12380633（Front Comput Neurosci 2025） |

写成式子：**代价泛函**

```
C[E] = Σ_{e∈E} d_e            （材料 / 电缆长度）
     + bf · Σ_{e∈E} d_e      （经 bf 加权的传导延迟项；延迟 ∝ 长度）
     = (1 + bf) · Σ_{e∈E} d_e,     bf ∈ [0, 1]
```
bf = 0 → 只最小化电缆（对应上面原文第一句）；bf = 1 → 电缆与延迟等权。

## 二、本节自己做的推导：从泛函到 λ

把"选哪条连接"松弛成距离上的**分布** p(d)（每个单位连接按距离落在 d 处的密度），引入无序度尺度 T（与距离同量纲 mm），求代价约束下的**自由能**极小：

```
F[p] = Σ_i p_i · c_i  −  T · H(p),   c_i = (1 + bf) · d_i,   H(p) = −Σ_i p_i ln p_i
```

对约束 Σ_i p_i = 1 作变分（Lagrange 乘子 μ）：

```
δF/δp_i = c_i + T (ln p_i + 1) − μ = 0
⇒ p_i ∝ exp(−c_i / T) = exp(−(1 + bf)·d_i / T)
```

**结论（本节的中心式）**：

```
λ = (1 + bf) / T          （λ 单位 mm⁻¹，T 单位 mm，bf 无量纲）
```

即：**指数距离律不是经验拟合，而是"材料–延迟权衡 + 无序度"这条泛函的极小点；λ 就是这套权衡的 Lagrange 乘子**。

## 三、数值求解与验证（求解件实跑）

在 600 档距离网格（0.01–2.20 mm）上用**镜像下降**最小化 F[p]，再从 log p 对 d 的斜率反读 λ：

| bf | T (mm) | λ 数值解 | λ 解析 (1+bf)/T | 相对误差 |
| --- | --- | --- | --- | --- |
| 0.00 | 1.0 | 1.000 | 1.000 | **0.00%** |
| 0.50 | 1.0 | 1.500 | 1.500 | **0.00%** |
| 1.00 | 1.0 | 2.000 | 2.000 | **0.00%** |
| 1.00 | 0.5 | 4.000 | 4.000 | **0.00%** |

bf 扫描（T = 1.0 mm 固定）：λ = 1.000 / 1.250 / 1.500 / 1.750 / 2.000 —— **严格线性**，与 λ=(1+bf)/T 逐项相等。

**负例**：T → 0（删掉熵项）时分布**塌缩到单个档**（最大概率质量 1.0000），斜率不可拟合 —— 判据能察觉"退化解"，不是无条件通过。

## 四、反演：文献 λ 对应哪套 (bf, T)

λ 只锁定**组合** (1+bf)/T，单独拆分需要独立测量其一：

| bf（材料/延迟权衡） | 由 λ=2.0 mm⁻¹ 反解出的 T |
| --- | --- |
| 0.0（只省材料） | 0.500 mm |
| 0.5（各半） | 0.750 mm |
| **1.0（等权，文献原文的上端）** | **1.000 mm** |

⇒ **bf = 1（电缆与延迟等权）配 T = 1.0 mm，恰好给出 λ = 2.0 mm⁻¹** —— 也就是前一轮从文献验证区间里采用的那个值。两条独立路径（文献验证区间；本节的泛函极小）**在同一数值上闭合**。

## 五、与实现件的关系（互不污染）

- 实现件 `bn_grow_v2.py` 只使用 λ（默认 2.0 mm⁻¹，出处写在代码注释里）；
- 本节解释 λ **从哪来**、以及它与 bf、T 的关系；
- 三个历史 λ 对照：设计值 0.851（低于文献验证区间）、尺度反推 5.117（高于区间上沿；**注：它不是反转临界** —— 复测显示反转点是 λ*≈2.031（长边占比谷底，占比 0.370），上行穿越 0.5 在 λ≈2.796；原 5.117 只是扫描网格点的浮点回显，见台账第二十六节）、**文献值 2.0（= 泛函 bf=1、T=1 mm）**。

## 六、边界与未尽事项

- 本节解的是**松弛问题**（距离上的分布），不是组合版的严格最优树；严格版即 Euclidean Steiner 最小树，文献原文亦注明该问题在计算上困难（"Steiner tree problems are considered …"）。组合版求解器未做。
- λ 锁不住 (bf, T) 的绝对刻度：要拆开需要独立测量 bf（材料/延迟的实测权衡）或 T。
- 泛函的两侧权重来自文献的**定性**形式与实测效率 ε_spiny = 0.86 ± 0.04；bf 的具体生物取值本节未取得。
